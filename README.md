# Apple Stock Market EDA

## Project Overview
This project performs Exploratory Data Analysis (EDA) on Apple's historical stock market data using Python, Pandas, NumPy, and Matplotlib.

## Objectives
- Analyze Apple stock price trends
- Calculate daily returns
- Study trading volume patterns
- Generate moving averages
- Visualize long-term stock performance

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset
Apple Historical Stock Data (AAPL)

## Analysis Performed
- Data Exploration
- Missing Value Analysis
- Statistical Summary
- Daily Return Analysis
- Moving Average Analysis
- Trading Volume Analysis
- Price Trend Visualization

## Key Insights
- Apple has demonstrated strong long-term growth.
- Daily returns reveal both growth and volatility periods.
- Trading volume varies significantly across market cycles.
- Moving averages help identify broader market trends.
